# Sevens

A free calculator for IB Diploma students: total out of 45, diploma check, and offer planner.

Live URL: https://sevens.example/

## How the rules are sourced

Every rule comes from the IB DP passing criteria page (https://ibo.org/about-the-ib/what-it-means-to-be-an-ib-student/recognizing-student-achievement/about-assessment/dp-passing-criteria/), checked on 2026-09-24, and from the May 2025 final statistical bulletin for context. The TOK/EE matrix is the ibo.org matrix. No official grade boundaries are bundled.

Rules checked on 2026-09-24.

## Develop

- Node 22 LTS, Vite, TypeScript strict, Preact.
- `npm install`, `npm run dev`, `npm test`, `npm run build`.
